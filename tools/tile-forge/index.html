A small guide to connected tiles.

  1. Choose your pixels. Load a PNG, set its tile size, then click the material cards to choose cells from the atlas. You can mix cells from different PNGs. Derive face from upper tile works with arbitrary artwork; choose a face tile to override it.
  2. Choose the boundary. Floor blends two surfaces. Wall adds a vertical face below a wall top. Chasm keeps the upper floor intact and adds a rim and a falling face over the lower tile. Select a dark lower tile for a void.
  3. Paint the difficult cases. Try narrow corridors, islands, and inward corners. Seam check repeats the selected neighborhood tile to expose texture repetition; it is not a promise that arbitrary edge shapes tile against themselves.
  4. Keep it reproducible. Save project embeds the source images, parameters, and painted scene. Open project restores them locally.
  5. Export. The ZIP includes PNG sheets, individual tiles, metadata, a Tiled atlas descriptor, and the preview. A 16px export matches Sil-More’s existing 256-slot atlas dimensions. The game now draws material-independent floor / wall connections and chasm edges automatically. Custom artwork exports still need an explicit material mapping in the renderer.

For best results, choose seamless base tiles. This tool preserves the supplied texture; it cannot repair a visible seam already inside the source artwork.
